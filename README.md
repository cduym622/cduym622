## Current Project:

### [Job Applications Tracker](https://github.com/cduym622/applications-tracker)

This project is a full-stack application built to help job-seekers keep track of their applications and interviews. 
Users create an account and are greeted by a dashboard showing their applications grouped by status, as well as upcoming interviews.

This currently application consists of:
* A frontend with authentication built on TypeScript and React
* A backend API built on the Django REST Framework
* A PostgreSQL database to hold user data

Future Work:
